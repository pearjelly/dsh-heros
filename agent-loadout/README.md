# 深度荣耀 · DSH-Heros

在 DeepSeek Harness 里给智能体选预设、配工具和插件。开局前看这套出装能做什么，实战后看它调用了什么、交付了什么。

[安装指南（Web 和桌面版）](https://github.com/pearjelly/dsh-heros/blob/main/README.zh.md#安装) · [21 秒演示（MP4）](https://github.com/pearjelly/dsh-heros/releases/download/v0.67.1/dsh-heros-promo-standard-narrated-zh.mp4)

## 同一张补给卡，两种交付

安装后，从 DSH 侧栏打开 **深度荣耀 → 装备库 → 英雄同题试玩**。启用受支持的原装标准模式和极简模式后，选「可打开的原件」，再用两位英雄分别打开并发送内置任务。

[![灯塔试玩界面，选择交付原件或摘要，再选标准模式或极简模式][trial]][trial]

两局跑完，从会话打开 **查看试玩对照**。这次标准模式附上了补给卡原件，极简模式读到了卡片，但只交了文字。想让极简模式也能附文件，可以加一件 **交付物预览**，用同一道题再试。

[![两局的实际交付对照，标准模式附上补给卡，极简模式没有附件][results]][results]

## 带上出装做自己的任务

从大厅点 **去配装**，选好英雄和装备，再点 **用当前出装做任务**。选自己的文件、写下任务，核对装备后进入 DSH 草稿。常用的组合可以存为出装方案，下次接着用。
