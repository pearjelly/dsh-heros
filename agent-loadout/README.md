# 深度荣耀 · DSH-Heros

从 DSH 的侧栏打开 **深度荣耀**。插件随 DSH 的语言设置切换，英文界面显示 **DSH-Heros**。在英雄阵容中选择 Agent Preset，在装备库中点选或拖动装备，再按 **锁定阵容并开局**。阵容会用于所选工作区的新会话，之后可从已保存阵容中再次选择。全屏与游戏音效可单独开启。

点 **英雄图鉴** 可按英雄名称、预设 ID、说明或已识别的自带能力搜索当前 Profile 的预设。点头像可以查看立绘和能力。预览其他英雄时，会显示这套阵容里哪些装备能保留、哪些需要确认替换、哪些会卸下。按 **选择英雄** 才会切换；无法加载的预设可在图鉴中查看原因。

英雄图鉴和装备库可按 **职能** 筛选。原生工具按已知工作用途分类。第三方包可声明英雄、插件和工具的职能。未声明的工具根据实际注册的工具名和简介开头的动作归类，MCP 工具按各自的操作名归类。插件和组合包可继承实际提供的工具职能。同名工具切换来源时，装备详情显示所选来源的职能。无法判断用途的英雄和装备归入 **专精**。立绘的光色和边纹随整套出装、工具来源和卸下的自带装备变化。试装和阵容对照会并排显示两套立绘和装备图标，开局后可用快捷栏的边纹认出同一套出装。备战时换装会出现对应的职能动效，点击立绘上的装备图标可查看详情。实际能力可在 **阵容对照** 和开局后的 **对局装备** 中核对。

预览其他英雄时，**切换英雄对照** 会以当前出装为基准，列出候选英雄预计新增、移除的能力，以及工具来源和就绪时机的变化。可以在 **对照范围** 中查看候选英雄的自带能力，或先看确认替换后的结果。当前出装有待处理的装备时，可先对照当前英雄的基础阵容。

英雄图鉴的 **实战装备** 按最近使用时间显示该英雄的装备结算。一次回合计一次装备使用，原生操作结算单独显示。同名工具有多个可核验的来源时，可以查看各来源参与过的回合。点 **查看装备** 可回装备库核对装配，或回看这件装备最近结算的对局。更新时会从当前 Profile 仍保留、能确认英雄的旧结算恢复实战记录。

在 **英雄图鉴 → 实战记录** 可以翻阅这位英雄已经结算的工作回合，查看当时获得经验的装备、已核验的来源和执行过的装备操作。队友回合记在实际执行的英雄名下。点 **用本回合打法备战**，可从原回合选一件装备筹备试炼，或选两件筹备连携，再确认新的任务目标。已经归档且仍保留的回合也可以使用。原会话关闭后，如果记录里保存了可复用的来源和依赖，开局委托会提供 **收藏并装上原来源**。

在 **装备库 → 实战搭配** 可以按实际使用记录查看英雄和当前基础阵容的装配状态。同名工具可按核验过的来源筛选，查看各英雄使用这个来源的回合数。点 **查看英雄** 可在图鉴核对该英雄的这件实战装备，再决定是否切换。原回合仍保留时，可直接回看该来源的对局。

在装备详情点 **给英雄试装**，可直接查看还没用过这件装备的英雄。工具可以选定具体来源。试装会列出能力变化、就绪时机，以及要换下或恢复的装备。为当前英雄试装时会沿用已选装备，并在采用前列出因同名工具冲突而需要卸下的装备。换一位英雄时从对方的基础阵容试装。确认后可采用试装或直接筹备装备试炼。

在试装里选 **加入第二件装备**，可检查两件装备能否在同一位英雄身上保留所选来源。面板会显示就绪时机、连携方式、战旗与经验。同回合指定操作可以选发动动作。分阶段连携会标出等级差距，解锁后可以选择先做什么、看过准备结果后再发动什么。点 **试装并筹备连携** 后，开局委托会带入两件装备、来源和已选步骤。

点 **预览试装** 可选这位英雄实际使用过的工具来源，并对照当前出装查看来源变化、新增能力和需要卸下的自带装备。采用后会把该英雄的基础阵容和试装装备载入备战草稿。原来源恢复可用时可重新核对；同名工具的其他历史来源可以单独预览。

在装备详情点 **筹备试炼**，可为当前阵容里的装备设定任务。可直接加入的装备也支持 **装备并筹备试炼**。历史搭配的 **试装并筹备试炼** 会带入所选英雄及工具来源。开局前可以选择基础试炼或指定操作，填写本次工作的目标，再确认委托。工具来源变化时，开局委托会提示核对原选择。

英雄和装备都达到 Lv.3，且这位英雄用该装备累计完成 3 次实战结算后，可在 **实战装备** 中将它设为 **招牌装备**。每位英雄可展示一件，随时可以换上其他已解锁的装备或收起。徽记会显示在英雄立绘和对局快捷栏，用于外观展示。工具徽记会记住所选时最近核验的来源。

**英雄图鉴** 和 **装备库** 会显示被 DSH 版本要求挡住的已安装插件，列出当前宿主、插件版本和依赖要求。其余已加载能力可照常开局。旧预设引用 `{{cwd}}` 时，从 DSH 会话读取实际工作目录，切换目录后也会更新。

旧版 DSH 的预设如果仍在 `.agent-presets` 目录，可以在 **英雄图鉴 → 接入旧预设** 查看来源和自带插件，再确认接入。当前 Profile 保存一份配置，继续使用原预设 ID，模块和资源仍可从原目录读取。已注册的同 ID 英雄会标为 **已在图鉴**。本机缺少插件时，可以选择 **接入可用配置**，在副本中停用找不到的插件以及缺少依赖的插件。图鉴会保留这份清单。

为已接入的英雄点 **核对旧预设更新**，可查看恢复候选、新增、移除和配置变化。确认后，DSH 验证并更新当前 Profile 的副本。更新失败时保留原配置。新开局使用新配置，正在运行的会话沿用开局阵容，英雄经验按原 ID 累积。当前支持的 DSH 版本会在预览里列出可由原生模块接替的旧工作流与子代理列表插件。

没有自带美术的第三方英雄和装备使用原创图集，配色和徽记由英雄、装备或工具来源决定。多个工具共用插件图标时，徽记也能帮助区分。战报和结算沿用已记录的来源，用户上传的图片优先显示。

在出装栏点 **保存为方案**，可给当前英雄、装备和来源命名，记录适用情形，留到以后开局。打开 **出装方案** 可以搜索、预览和采用，也可以先用 **与当前对照** 查看能力和来源的变化。调整同一位英雄的出装后，可以用当前出装更新原方案。方案保存在当前 Profile。移除方案入口后，历史对局仍可打开。

出装栏的 **阵容对照** 可以把待锁定阵容和基础英雄、另一位英雄或原会话比较。新增和移除的能力会展开对应的工作流选择与已登记操作。同名工具更换来源时，还会显示这次换源后新增和失去的已登记操作。配装预览沿用开局的组合规则，包含随装依赖和被替换的配置。开局后可在 **对局装备** 核对实际状态。

对照中可作为开局试炼的新增操作旁有 **筹备试炼**。点选后会把操作、装备和已确认的工具来源带入 **开局委托**。可以修改任务目标、补充首回合材料，再确认开局。

展开 **阵容对照 → 当前阵容打法**，可按装备、来源或操作搜索待锁定阵容的英雄操作、工具和插件试炼。换装后会重新核对打法。点 **筹备交付** 或 **筹备试炼** 可为所选操作填写任务，确认后再开局。

在 **英雄图鉴 → 英雄操作** 可以直接 **选用并筹备交付**。当前英雄的操作和阵容对照中的新增英雄操作可点 **筹备交付**。开局委托会选中这项操作，确认后用指定英雄完成回合，验收时获得 40 英雄 XP。

装备库的 **英雄自带** 可卸下英雄原本加载的工具插件。详情会列出一起卸下的依赖项，出装栏和对局装备会保留卸下记录。原预设继续作为基础阵容使用，英雄的身份指引随英雄加载。

会话输入栏上方的快捷栏显示当前英雄和已选装备。装备边框对应职能，状态点随会话更新。装备从待触发或受条件限制变为就绪时，图标会短暂亮起。工具实际开始调用时，会显示工具名，已装备的工具或来源插件会按职能亮起，包括程序执行器和它正在调用的子工具。系统设为减少动态效果时，仍可通过文字和边框确认调用状态。点击图标可打开操作或查看状态。**对局装备** 可按职能筛选已选装备、实际注册的工具、会话插件和 Profile 装备。点 **回城换装** 会带回该会话的英雄、已保存出装和工作区。**锁定阵容并续战** 会在同一工作区用新阵容接续已完成的对话，原会话仍可打开。也可以选择 **另开新局**，在所选工作区从空白对话开始。已保存阵容可在备战大厅用 **复制并调整** 新建一套出装。

已保存出装方案后，快捷栏会出现 **切换出装**。选一套方案可预览英雄、装备和相对当前对局的能力变化。确认后在当前工作区准备续战，正在运行的回合会先完成。准备好后点 **进入续战**。

在快捷栏打开 **成长与委托**，可查看英雄等级、装备熟练度和本局经验记录。成功完成一个用户回合，英雄获得 12 XP，成功调用的每种工具获得 8 XP。能确认实际提供了成功调用的工具，或从装备入口发送了操作并完成回合的插件、组合包和工作流装备获得 4 XP。回合内同件装备只结算一次，续战继承的回合只保留原记录。

同一个工具可以有多个装备来源。每个完成的回合以该工具首次成功调用的来源为准，能核验来源时，这笔工具经验同时记入该来源的熟练度。装备详情可切换来源查看各自的等级，结算会注明本回合计入了哪一个来源。升级时会从仍保留且能确认来源的旧回合恢复这部分记录。

PTC 批量操作会按每件工具的 DSH 最终结果结算。程序处理了其中一项失败后继续运行时，成功的工具和对应插件照常获得经验。同一种工具在该回合成功多次仍只结算一次。失败项及其来源可在对局战报核对。

DSH 在本机运行子智能体时，首个委派和上级交给它的后续任务都按实际完成回合结算。经验归执行工作的英雄、工具及可确认的装备来源。发出结果通知和上级回收结果属于原任务的一部分。上级对局的 **结算记录** 会标记队友回合，可点 **回看队友工作** 打开对应的子会话。

从主对局快捷栏点 **组队**，可以按英雄名或出装搜索，选一位已登记的英雄和它的默认或已保存出装。写明任务和材料路径后点 **派遣**。DSH 会在本局工作目录创建队友会话，使用本局选定的模型及 DSH 原生子智能体权限。可以留在主对局处理其他工作，或点 **查看队友对话** 跟进任务。

在 **对局装备 → Profile 装备** 可查看当前已加载的 Profile 插件和组合包、累积经验和可用操作。从该装备发送操作并完成回合，装备获得 4 XP。成功调用 Profile 工具时，工具获得 8 XP。来源可核验时，提供该工具的插件及其已加载的组合包各获得 4 XP。普通回合按实际使用结算，连携和试炼按委托条件验收。

对局装备会列出能确认来源的 **原生命令**。可搜索 `/命令名` 找到插件、查看参数并复制到 DSH 输入栏。每场对局首次成功执行同一装备的同一命令时，该装备及对应的已加载 Profile 组合包各获得 4 XP。战报会记录每次命令的执行状态，失败或重复执行也可回看。

已登记的 **面板操作** 会出现在装备详情和对局装备中。操作在原插件界面完成，收到宿主确认后进入战报。每场对局首次完成同一件装备的同一操作，插件和对应的已加载组合包各获得 4 XP。Fast 0.1.4 的速度开关已接入，可以在会话模型菜单中启用 Fast 后查看结算。

安装计划批注 `dsh-plan-note@0.1.2` 后，可在支持计划模式的英雄对局中提交评审批注。用插件的 **发送批注** 提交修改意见，DSH 收到答复后即可结算这项面板操作。战报记录操作名称和实际来源。计划评审继续沿用 DSH 的审批和修改流程。

在 DSH 实际生成摘要并完成上下文压缩后，执行压缩的插件在本局首次获得 4 XP。支持手动 `/compact` 和已启用的自动压缩。提供压缩的装备在当前对局可选择 **压缩上下文** 作为试炼或分阶段连携的目标。成功的试炼可验收 32 XP，经验记录保存操作名称。

快捷栏上方的结算提示会显示实际出手的装备和获得的经验。已在快捷栏里的装备会亮起金边，同名工具按实际调用的来源匹配。点提示里的装备可直接定位到该件装备的结算，点 **查看结算** 可核对完整记录或打开对局战报。新解锁的招牌装备可从结算直接 **设为招牌**，徽记会显示在对应英雄的立绘和快捷栏。委托达成后可从提示直接进入验收。隐藏提示后，仍可从 **成长与委托 → 查看本局结算** 分页翻阅本局和队友的结算。其他对局产生的新结算时，旧结算会归档到原对局。更新前已经被滚动替换的记录，仍可通过原对局战报核对有记录的操作和调用。

在回合结算点 **用本回合打法备战**，可从参与过的装备中选一件做下一局试炼，或选两件做连携。选两件后可在回城前查看可用连携、奖励和距离分阶段解锁还差的经验，选好的操作会带入开局委托。开局委托会核对装备和工具来源，列出采用原打法时需要换下或恢复的自带装备。可在这里确认换装，也可以选择 **改用当前来源** 后再确认委托。该回合有一项可用于挑战的操作时，会带入该操作供你核对。填写新的任务目标、确认委托后再锁定阵容。

记录了操作来源的原生命令、面板操作和上下文压缩结算可以 **筹备本局试炼**。同一次操作为插件和组合包结算经验时，选择其中一件作为试炼装备。系统会核对本局是否仍可使用原操作。接下委托后再次成功操作，验收时为所选装备结算 32 XP。已领取试炼奖励的装备会从这项操作的候选中移除。较早的结算可以回看，也可以在 **成长与委托** 中直接选择当前可用的操作。

开始新回合前，可为实际工作接一项 **交付委托**，由你验收任务成果后为英雄结算 30 XP。也可挑一件工具、工作流或插件做 **装备试炼**，成功使用工具或在插件已加载时完成回合，验收后为该装备结算 24 XP。每场对局可同时保留一项委托，随时可以放弃。

**交付委托**可以指定英雄操作。标准模式可以选「核对后交付」，PTC 模式可以选「编排批量处理」，招聘顾问可以选「区分证据与判断」。第三方预设也有「按当前预设交付」，并支持发布者提供和用户自定义的操作。可在 **英雄图鉴** 查看各位英雄的操作，在开局前或对局内选择交付方式。用当前英雄的入口发送指定操作、完成回合并验收后，为该英雄结算 40 XP。

在支持队伍任务的 DSH 版本里，开启 **智能体团队协作**，在对话里创建共享任务。可从 **交付方式** 选择本局尚未完成的任务。DSH **任务板** 显示任务完成后，由你验收交付，接下委托的英雄获得 40 XP。验收前重新打开任务会撤回待验收状态，再次完成即可验收。每项队伍任务的交付经验限领一次，委托随原对局的任务板保留。

在 **组队 → 工作来源** 可以选本局共享任务，也可以在当前交付委托中点 **为此任务派遣队友**。任务需要依赖已完成、尚无负责人。选好英雄和出装后，DSH 先在任务板登记该队友为负责人，再由队友按原任务说明执行。派遣期间任务有变动时，可核对最新任务后重新选择。队友获得实际工作经验，委托由接下它的英雄验收结算。

带有装备操作的工具、工作流和插件，可以在 **装备试炼** 里指定一次操作。例如为「证据核验」选择「暂缓提交」，从成长面板打开这项操作，确认后发到会话。回合需要正常完成，装备仍须达成原来的使用条件。完成后由你验收，为该装备结算 32 XP。已识别的操作可以在开局前选择，运行时可用的操作也可在对局内选择。结算与委托簿会记录达成的操作。

已识别的 **原生命令** 和 **面板操作** 也可作为装备试炼目标。在本局接下委托后，从 DSH 输入栏执行指定命令，或通过插件原有界面完成指定操作。宿主确认成功后即可验收，为所选装备结算 32 XP。同一 Profile 内，每件装备来自同一插件来源的每项操作可领取一次试炼奖励。已识别的面板操作可在开局前选择，命令在注册到当前对局后可选。委托簿记录操作名称与达成方式。

在 **对局装备** 选 **使用** 可用当前工具完成给定任务，包括执行器提供的工具。选 **操作 → 核验装备作用** 可为已加载的插件或组合包指定一项工作，让助手列出能核对的影响和待确认条件，再决定继续、补齐条件或回城换装。两项操作都可作为试炼目标。回合触发的已装工具可以从 **安排** 发送任务，包括自定义操作和已识别的来源插件操作。也可以在开局前把这些操作设为试炼目标。试炼在所选来源的工具实际注册并成功调用后才可验收。

另开新局时，可以在备战栏打开 **开局委托**，用当前出装选择试炼或连携装备，也可以安排交付或接力。可选填首回合要执行的工作和材料。锁定阵容后点 **打开首回合任务**，核对内容再发送给助手。指定的英雄或装备操作会带入任务内容。改动阵容后会提示重新核对委托，临时注册的工具可在对局内加入挑战。已接下的委托可从 **成长与委托** 打开任务，接力或换装续战时会带上原来准备的任务内容。

英雄和装备达到等级 3、5、6 时，依次解锁 **熟练**、**精通**、**大师** 边框。回合结算会提示新解锁的边框，默认自动展示最高已解锁的样式。可以在备战大厅的 **英雄外观**、**装备外观** 中预览和更换，也可以直接在对局的 **成长与委托** 中更换。选择保存在当前 Profile，同一个英雄或装备在其他阵容也会使用该边框。等级影响外观和可选的挑战节奏。

有两件装备要一起完成一项工作时，可接 **连携挑战**。同回合连携至少需要一件工具。在同一个成功回合中，工具需要成功调用，插件或工作流装备需要加载就绪。成长面板会列出上一回合缺了哪一件。验收后，英雄获得 24 XP，两件装备各获得 16 XP，并解锁一面以任务目标命名的战旗。同一英雄与同一组装备只结算一次基础奖励。

在 **开局委托** 或 **成长与委托** 选好两件装备后，会列出当前可接的连携方式、所选来源的战旗和验收奖励。选择 **同回合指定操作** 或 **分阶段连携** 后，再从该组合可用的操作中选择。

已接下的连携会随其他对局的结算更新可领经验。如果另一局已经领取同一来源的同一项战旗奖励，这局完成后仍可 **确认验收并记录**。结算与委托簿会保留本局成果和装备来源，战旗及经验只发放一次。

委托中能确认具体工具来源时，必须成功调用该来源。换用同名工具的另一个来源，可重新接下连携并解锁一面可单独展示的战旗。每组英雄和装备共享基础连携、连携操作和分阶段连携的额外经验额度。战旗收藏可以按来源名称检索，并在详情中核对来源。

开局前或对局内，可以为连携挑战再选一项 **连携操作**。例如用档案工具取证，再打开「交付前复核」的「复核交付草稿」。从委托发起操作后，需要在同一回合成功调用辅助工具，并满足所选操作的装备条件。两件装备都是工具时，辅助工具须先成功返回，执行指定操作的工具再成功返回。验收后，战旗会记录达成的操作，两件装备各额外获得 8 XP。已经解锁的战旗也能通过指定操作升级一次，保留原战旗和原会话，并结算这笔额外经验。

英雄和两件装备都达到 Lv.3 后，**连携节奏** 可选 **分阶段连携**。选择主装备的 **发动操作**，再为另一件装备选择 **准备操作**。辅助装备是工具时，也可直接安排它取证。例如先用「证据核验」标出证据缺口，看过结果后，再用「交付前复核」检查草稿。涉及助手操作的步骤需要在该阶段的新回合里完成，工具须成功调用，插件或工作流装备须加载就绪。

已识别的原生命令和面板动作也能用作准备或发动。例如先用计划模式的 `/plan` 进入规划，再用计划批注插件对草案提出修改意见。第二阶段只接受准备达成后的操作。插件和其组合包提供的同一项原生动作只可占一个阶段。

每面战旗可各记录一次同回合和分阶段连携。该英雄与这组装备首次验收分阶段连携时，两件装备各额外结算 16 XP。战旗与委托簿保留两步的操作和达成记录。同英雄换装接续时，会核对准备记录是否已带到新会话。

同一位英雄回城换装时，可以带着未完成的 **交付委托**、**装备试炼** 或 **连携挑战** 续战。新对局的 **成长与委托** 会显示目标装备在新阵容里的状态。点 **接续委托** 后，原目标和奖励随委托转移，从新对局的回合开始判定。连携会保留已继承回合的上次尝试，仍需在一个新回合中同时达成。已待验收的委托可以回原对局结算。

需要用两位英雄分工时，可接 **接力委托**。用首位英雄完成一个有效回合，再点 **回城交棒**，选择另一位英雄续战。到新对局的 **成长与委托** 点 **接棒**，完成一个新回合后验收。同英雄换装备时可选择 **接续委托**，已经完成的第一棒会随之带过去。验收为两位英雄各结算 24 XP，还可选一件在接力回合中有使用记录的装备嘉奖 16 XP。结算保留两棒的会话入口，便于回看各自的工作。

装备达到 Lv.3 后，可在接力委托里指定为 **接力装备**。两位英雄分别在各自的新回合使用它，工具需要成功调用同一已核验来源，插件需要有实际提供工具或执行装备操作的记录。点 **回城交棒** 会打开指定装备，便于给接棒英雄核对来源。同一对英雄首次用这件装备完成接力时，装备获得 32 XP，之后为 16 XP。互换英雄顺序或更换同一工具的来源仍使用同一首次奖励记录。委托簿保留两棒的对局和使用的装备来源。

从装备接力回城后，**接力阵容核对** 会随所选英雄和出装更新。当前阵容缺少接力装备或用了其他来源时，可查看需要卸下或恢复的自带装备，再采用接力来源。采用只调整备战草稿，之后可以锁定阵容续战。按条件启用和回合触发的装备会显示各自的就绪时机。

在 **英雄备战** 打开 **委托簿**，可按工作区、英雄、装备或任务名称查找当前 Profile 的委托。**待验收** 和 **进行中** 可以进入当前负责的对局，接续委托或交棒后入口会随委托转移。**已完成** 保留验收奖励、战旗和相关对局，即使本局的近期结算被滚动替换，也能查到委托记录。升级前仍在近期结算中的已验收委托会自动纳入委托簿。

在备战大厅打开 **战旗收藏**，可按英雄、目标或装备检索战旗，回看达成的会话，并为每位英雄挑一面展示。展示会随英雄出现在备战立绘、英雄图鉴和对局快捷栏，使用该英雄的已有出装也能看到。

连携战旗可点 **预览出装**，用当时的英雄核对两件连携装备、记录的工具来源和随之卸下的自带装备。点 **采用出装** 后可继续在备战大厅调整，再锁定阵容开局。原来源暂不可用时，可以先采用已核对的装备，再到装备库选择来源。预览只带入战旗记录的连携装备。

连携结算中的 **查看战旗与升级** 会打开对应战旗并核对出装。战旗详情列出还能完成的连携方式、距离分阶段连携所差的等级和可领经验。选择一种方式后，开局委托沿用这面战旗的英雄、两件装备和工具来源，可为新任务选择操作。验收后将新打法记到原战旗。

原装备和操作均可核验时，点 **复练原连携** 可把战旗里记录的打法带入开局委托。若已记录分阶段连携，会沿用该方式和原操作顺序。可为新一局修改任务目标和材料。达成后可验收并记录本局成果，实际完成回合和使用装备照常结算经验。战旗奖励沿用原领取记录。缺少操作凭证的旧战旗仍可恢复出装。

两位不同的英雄首次完成一次共享交付时，可解锁共同的 **协作战旗**。一位英雄接下交付委托，另一位英雄作为任务板负责人完成任务并在 DSH 标记完成，再由你验收。战旗保留两位英雄的分工和会话入口，两位都可以单独选择展示。互换角色仍是同一组搭档，后续交付照常结算经验。

在 **对局装备** 中点图钉，可把已就绪的工具、会话插件、可核验配置的 Profile 插件或组合包放到当前会话的快捷栏。包括 `run_code` 在内的执行器工具会跟随提供它的执行器。工具或插件暂时消失时槽位仍在，原来源回来后可继续使用。临时注册且没有可识别来源的工具跟随当时的注册实例。同名工具替代或已固定的 Profile 装备配置变化时，槽位会标为 **来源冲突**。工具指令会在调用时核验来源，已排队的 Profile 装备操作在结算时核对原配置。图钉保存在当前会话，可以随时移除。

换装续战后，打开高亮的 **对局装备** 可核对 **原对局快捷槽**。新阵容仍能提供原来源时，可以勾选沿用，包括保留原来源的回合触发工具。缺少来源、来源冲突和已在当前出装里的装备会显示各自状态。点击 **沿用所选快捷槽** 将入口固定到续战会话，也可 **略过**。

点 **待触发** 的工具快捷槽，可以填写材料并 **安排回合任务**。工具按原插件的条件注册，调用时会核对快捷槽选定的来源。原来源成功执行后结算工具经验。工具未出现时，战报保留安排记录。其他来源的同名工具触发时，战报显示来源冲突。

已固定且原来源可用的回合触发工具，可以在 **成长与委托** 中参加基础试炼或指定 **用工具完成任务**。从委托安排回合时，继续使用接单时选定的来源。原来源成功调用后才可验收。移除快捷槽后，可以从委托继续安排任务。

连携和接力也会记住这些工具的来源。接续前可在 **成长与委托** 核对装备是否就绪、待回合触发、来源冲突或原来源不可用。分阶段连携会标出当前阶段所用的装备。从委托打开任务时，会核对本阶段所需的来源。同回合连携会分别核对两件工具，接棒后沿用接力选定的来源。

回合运行时可选 **本回合结束后续战**，锁定下一套阵容再回原会话处理提问卡或查看进度。提问卡占据输入栏时，可以从会话标题栏 **回城换装**。DSH 在该回合结束的位置准备新会话。准备好后，从原会话快捷栏或备战大厅点 **进入续战**。等待期间可以取消安排。续战安排保存在当前 Profile，重启后可回原会话查看。如果原回合中断，可以沿用已选阵容 **重新排队**。

快捷栏的 **战报** 按回合显示装备操作、工具调用与结果、程序工具调用中的子工具，以及原生提问卡上选过的选项。装备有结算记录的本局回合可以直接点 **用本回合打法备战**。从 v0.29.0 起，能识别的调用来源随 DSH 会话日志保存，重启和续战后仍可核对当时执行的实现。被装备来源核验阻止的调用会显示所选来源和能识别的拦截来源。续战带入的回合标为 **继承记录**。旧会话按已有记录展示。从 v0.20.0 起通过英雄或装备入口发送的操作会显示对应名称，同一个 DSH 数据目录内的不同 Profile 可以读取这些记录。

在 **对局装备** 中点击已就绪的精选装备，可以把操作指令发给当前助手。装有 **证据核验** 时，可以发起核验让助手在缺证时提问，也可以直接选择 **继续补证**、**降级推荐** 或 **暂缓提交**。已注册的原生和第三方工具旁也有 **使用** 按钮，填写任务即可向助手指定该工具。指令沿用 DSH 的对话和工具权限。有回合正在运行时，指令在当前回合结束后按队列处理。

在英雄立绘旁选 **设置英雄操作**，或在装备详情选 **设置装备操作**，可以给已有预设、工具、会话插件和 Profile 插件配置多项自定义操作。每项可以填写用途、会话指令，以及使用时是否需要补充材料。操作保存在当前 Profile，在 **对局装备** 中打开。工具操作会带上实际工具名，按 DSH 的常规对话流程发送。

插件随包提供的操作也会出现在英雄图鉴、装备详情和对局快捷栏。可以在对局里展开查看发布者和指令，再选择是否使用。包括 `run_code` 在内的工具操作会随实际来源更新，可以用于装备试炼。通过装备入口发送的操作会记录选用的来源，排队后仍在调用时核验。自己添加的操作和插件提供的操作可以在同一个菜单里使用。

## 安装与打开

Web 使用 DSH CLI，桌面版使用应用随附的 CLI。支持 `0.2.1-rc.1` 至 `0.2.1-rc.5`，以及 `0.2.2-rc.1` 至 `0.2.2-rc.5`。每个第三方插件仍需满足它自己的 DSH 版本要求。

```sh
dsh plugin --profile web add -w /path/to/agent-loadout
dsh web
```

桌面 Profile 安装后，在下次完整启动 DeepSeek Harness 时加载。

```sh
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" \
  plugin --profile desktop add -w /path/to/agent-loadout
```

如果原生插件安装报告 `ERR_PNPM_ADDING_TO_ROOT`，请在对应 Profile 的 `pnpm-workspace.yaml` 加入 `ignoreWorkspaceRootCheck: true`。使用 pnpm 9 的 Web Profile 在同目录的 `.npmrc` 中加入 `ignore-workspace-root-check=true`。[pnpm 工作区设置](https://pnpm.io/workspaces#ignoreworkspacerootcheck)

在大厅的 **装备库 → 证据核验** 点 **试一次证据取舍**（**Try an evidence choice**）。也可以从 **灯塔补给行动** 打开 **灯塔证据取舍**（**Lighthouse evidence choices**）。选 **关键证据缺失**（**Missing key evidence**）或 **证据齐全**（**Evidence available**），点 **开始证据取舍**，在独立的标准模式会话核对并手动发送任务。开局前返回装备详情，可以继续编辑原出装草稿。

补给卡没有两节备用电池的依据时，**证据核验**通过 DSH 原生提问卡提供继续补证、降级推荐、暂缓提交三个选择。补给卡能够核实两罐灯油时，可跳过提问继续交接。点 **查看取舍记录**（**View evidence run**）或从 **实战记录** 找回这局，核对实际工具调用、你选择的答案和已交付的文件。文件留在 DSH 对话内。

在练习记录里核对到一次证据取舍或一次证据齐全的交付后，点 **用这套出装做自己的任务**（**Use this loadout on my task**）。用自己的工作区和材料准备新任务，核对实际装备来源后在原生会话手动发送。可从 **查看任务结果** 核对本局的选择和附件，并把出装保存为方案。

个人任务留下可核验的证据取舍后，可在 **查看任务结果** 点 **换一件再试**（**Try one gear change**）。点 **核对卸下证据核验**，确认原材料、交付物预览及其原来源，再到独立会话手动发送同一任务。**证据换装对照**（**Evidence gear comparison**）保留两局原会话，分别展示实际调用、选择和交付。补证或暂缓可能留下零附件，复赛也可能出现其他提问。

完成一组可核验的个人对照后，从 **装备库 → 证据核验** 点 **查看证据换装记录**（**View evidence replay history**）。该视图只列出已完成的个人证据换装对照，支持按任务、材料或工作区搜索。选择一组，核对两局实际选择和交付，也可以打开各自的 DSH 原会话。材料在对照完成后发生变化，仍可查看历史记录。

对照完成后，在 **挑一套留到下次**（**Keep a loadout for next time**）查看两局的实际选择和附件。点其中一侧的 **保留这套出装**（**Keep this loadout**），核对这局装备和来源，再输入名称保存。保存后可以继续编辑原大厅草稿。在 **出装方案** 选择新方案，点 **用这套出装开新任务**，选择新材料并在新的 DSH 会话手动发送任务。

从 v0.95 起，从已核验的证据对照保存方案会记录所选一局。在 **出装方案** 点 **查看实战来源**（**View tested source**），可回看这局的原生选择和附件。方案改名、编辑说明，或材料在完成后发生变化，仍可打开实战记录。用当前出装更新方案会解除来源链接。分享码只包含可复用的出装信息，实战关联保存在本地。

第一次想体验换装，在大厅打开 **灯塔补给行动 → 灯塔换装练习**，点 **开始换装练习**。插件准备独立练习工作区和标准模式的直接交付阵容，无需先建工作区或保存方案。在新会话核对并手动发送待发任务，打开实际交付的 `02-lighthouse.md`，再在会话里点 **查看练习记录** 核对这局结果。

基准通过核验后点 **换一件再试**。用 **练习推荐** 加装 **交付前复核**，先预览能力变化，再打开独立的 DSH 会话，手动发送同一任务。在提问卡选择确认交付或退回修改，可回到对照核对该选择和实际交付情况。两局沿用同一份样例材料，可从 **实战记录** 打开各自原会话。

核对灯塔练习结果后，可在直接交付或复核后交付一局点 **用这套出装做自己的任务**（**Use this loadout on my task**）。从 **实战记录** 找回练习也可以使用这个入口，无需先保存出装方案。选择已有的个人工作区，用 **浏览文件** 选择自己的材料，填写 **新任务说明**。点 **核对材料和出装** 查看当前英雄、装备来源和待发任务。点 **确认并打开会话** 后，在独立的 DSH 会话里手动发送。用交付前复核时，在新会话的提问卡上确认或退回修改，并从该会话核对实际交付文件。

用练习出装做完自己的任务后，在会话里点 **查看任务结果**（**View task result**）。结果显示实际工具调用、提问卡选择、交付文件和本局已结算的经验。兼容 v0.82 任务里可核对的原会话记录。需要查看附件时，可以用当前 DSH 支持的 **打开交付文件**，也可点 **查看原会话** 查找文件。找到了值得复用的打法，就点 **核对本次出装**，检查本局装备和来源，再点 **保存为方案** 自己填写名称。

个人任务的材料通过核验后，可在 **查看任务结果** 点 **换一件再试**（**Try one gear change**）。选择加装、卸下或替换一件装备，核对变化，再在同一个工作区打开独立的复赛会话，手动发送沿用的任务。对照中的基准链接到原个人任务会话，可分别核对两局的真实工具调用、提问卡选择和交付文件。

材料变化或旧任务缺少校验记录时，可点 **以当前材料重跑原局**（**Rerun baseline with current material**）。在重跑页面核对或重新选择材料，也可编辑带入的原任务说明。确认出装后在新的基准会话手动发送。v0.82 和 v0.83 的原任务结果继续按实际记录展示。

用自己的材料完成标准模式个人复赛，加装或卸下交付前复核后，已核验的对照会显示 **两局实测结果**（**Observed handoff results**）。每一侧分别显示用户实际选择和交付情况。分别标明所选材料、其他交付和零交付。其他位置的同名文件计入其他交付。原会话和具体工具调用可继续核对。在符合条件的一侧点 **保留这套出装**（**Keep this loadout**），核对这局装备和来源后再 **保存为方案**、输入名称。保存后可从该方案用新材料开局。

选择加装或替换装备时，可用 **按名称或用途搜索装备**（**Search gear by name or purpose**）查找名称、用途或装备提供的选择。替换时先选要卸下的装备。输入「退回修改」或 “request changes” 都可以找到 **交付前复核**。改写或清除搜索词会保留已选的装备和来源。点 **核对换装** 查看本次单件改动。

用标准模式直接交付所选文件后，打开个人任务的 **换一件再试**。材料仍可核验，且单独加装复核能保留原交付工具和来源时，可点 **试试交付前复核**（**Try Delivery Review**）直接进入换装预览。核对变化后点 **打开换装会话**，到独立会话手动发送同一任务。对照页可分别核对两局的真实交付，确认后成功交付会显示复赛附件，退回修改会记录选择和实际交付情况。

装有 **交付前复核** 的已核验个人任务及其首次复核复赛，在记录真实的提问卡选择并交付所选文件后，可以从 **换一件再试** 进入 **试试直接交付**（**Try direct delivery**）。材料和原交付来源需仍可核对。先核对只卸下复核的预览，再打开独立会话手动发送。对照保留原局已记录的选择和附件，也展示新局实际发生的调用、选择和交付。

在大厅打开 **灯塔补给行动** 可以直接体验标准模式。侦察路线用 `glob` 找出补给卡的位置，交付路线还会装上 **交付物预览**，把卡片送进对话。锁定后在独立的示例工作区开启会话，点 **打开首回合任务**，由你确认并发送。

在大厅打开 **同题对照**，可以让侦察和交付两套标准模式出装处理同一题。每套出装各开一个新的示例会话，由你打开并手动发送同一段任务。做完一局可以回到对照继续另一局。结果以各自会话实际记录的工具调用、DSH 提问卡上的选择和交付文件为准。看过两个结果后，可判断知道路径是否已经够用，或者是否要把文件直接交到对话里。从对照打开原会话后，可用战报或结算里的 **核对已验证出装** 试装复练或保存为方案。

也可以在 **实战同题对照** 选择已有工作区，点 **浏览文件** 选择两局都要用的材料。在同一工作区分别用 **直接交付** 和 **复核后交付** 开启独立会话。两局各有一段相同的待发任务，需要手动发送。回到对照后，可核对两局实际调用、仍待回答的 DSH 提问卡、确认或退回修改的记录和实际交付的文件名。到原会话回答提问、打开产物或查看本回合用过哪些装备。

在大厅打开 **实战记录**，按任务、工作区或材料搜索之前的对照。找到一组对照后，打开原会话核对实际附件和提问卡上的选择，也可以查看这条路线已经验证的出装。复核路线可结合当时的选择判断是否值得保留，再试装复练或打开 **保存为方案**，为保留的阵容填写新名称。

在 **出装方案** 中选择 **用这套出装开新任务**。选择已有工作区，点 **浏览文件**。在 **选择材料文件** 中浏览目录，或按文件名和相对路径搜索。选中的文件会填入相对路径，支持中文和带空格的文件名。重新选择材料会保留已填写的任务。点 **核对材料和出装** 预览当前可用的英雄、装备及工具来源。点 **确认并打开会话** 后，在新的 DSH 会话核对准备好的任务再手动发送。用复核后交付的打法时，可以先审草稿，在这次会话的提问卡上确认交付或退回修改，再查看本次交付的文件。

选中出装方案后，点 **与另一份方案同题对照**。选好另一份方案和共用的工作区、材料、任务后，点 **核对两套方案**，查看能力差异、工具来源和开局就绪情况。两套出装各自打开新的 DSH 会话，由你手动发送任务。完成后可从 **实战记录** 回到对照，核对真实调用、提问卡选择和对应的交付文件，再打开原会话查看产物或保留出装。

如果已保存同一组证据换装对照的两侧，在任一方案点 **用新材料再试这两套**（**Retest these loadouts with new material**）。另一侧有多份时先选一份，再为两套方案选同一个工作区和一份新材料，填写新任务。在两局各自的 DSH 会话手动发送，再核对本次实际选择和交付。其他方案组合也可以从 **与另一份方案同题对照** 开局。

复测完成后，在 **这次复测有什么变化**（**What changed in this retest**）按方案查看原实战与本次复测的实际选择和附件。点 **查看原实战对照**（**View original comparison**）核对会话。v0.97 起新开的复测保留原对照关联，之后编辑或更新方案装备也能回看。v0.96 的复测在两份方案仍能核对到对应的来源时也可查看。

在实战同题对照或方案同题对照中，从已完成且通过核验的一局点 **换一件再试**（**Try one gear change**）。选择加装、卸下或替换一件装备，查看能力和来源变化。沿用基准局的工作区、材料和任务，在独立的新 DSH 会话里核对并手动发送任务。材料变化后，需要另开同题对照建立基准。复赛可以从 **实战记录** 找回，基准局和复赛分别可打开原会话，核对实际工具调用、提问卡选择和交付文件。

已核验的复赛可以继续点 **换一件再试**，用这局作为下一局的基准。每次沿用原始材料和任务，只改一件装备，再到新的会话手动发送。点 **查看上一组对照** 可逐局回看装备变化、用户选择和交付文件。可从 **实战记录** 选择任意一局已核验的结果，核对并保存出装为方案。

进到自己的工作区后，在大厅打开 **实战打法**。直接交付与复核后交付都用标准模式和交付物预览，后一套增加交付前复核，给草稿加上确认或退回修改的选择。先看能力变化，再采用并锁定。使用中的会话可以按原有方式换装续战。

在 **出装方案** 选择已保存的方案，点击 **分享方案**。分享码描述预设、装备来源、版本和卸下的自带装备。导入时以接收方的 DSH 实际注册结果核对同名工具、随装依赖和版本。检查通过后采用为大厅草稿。方案说明、本机路径、自定义配置和会话数据留在原 Profile。

如果原方案的装备或版本在本机无法核对，在导入预览打开 **比较本机换装**。可以选择同接口的其他来源、搜索用途不同的装备、跳过某个装备，或保留原本要求卸下的自带装备。**核对本机换装** 会按本机预设重新验证整套阵容，给出实际能力和依赖变化。确认后由用户通过原有流程开局、续战或保存。

在自己的战报或结算打开 **核对已验证出装**，按实际回合或已验收连携核对装备来源。界面分别显示成功工具调用、操作记录和验收时的就绪情况，并列出对应回合实际交付的文件名。可勾选需要复用的部分，试装复练或通过命名表单保存。

## 装备来源

- **英雄**来自当前 DSH 注册的 Agent Preset。英雄可使用声明预设的包或该预设加载的插件包所提供的立绘，其余使用内置立绘或默认图集。
- **形象**可在备战大厅通过 **更换立绘** 或 **更换图标** 使用本机图片。支持 4 MB 以内的静态 PNG、JPEG 和 WebP。上传的形象优先使用。恢复默认后，装备使用 DSH 识别的插件图标或默认图集。工具有多个来源时，图标随所选来源变化。
- **会话插件**来自预设和已保存阵容的实际组成。插件组整体装配，保留组内依赖、隔离设置、原始配置和加载目录。外部预设可保留相对资源和 Cordis `!!js` 配置。同一份插件配置来自不同目录时，装备库会保留各自的来源。详情可查看来源英雄和换装影响。DSH 会在保存前验证组合能否加载。
- **随装依赖**根据 DSH 实际绑定的 Cordis 服务识别。选中一件装备后，详情会列出需要同时加载的同级插件，包括间接依赖。新阵容为复制来的预设服务建立自己的隔离实例。会话专属服务随各自的新会话加载。
- **会话专属插件**也可从运行中的会话发现。只要 DSH 有可保存的插件配置，装备库就能把它带到另一位英雄的新会话里，保留原插件组、加载目录和隔离设置。插件会在开局时由 DSH 加载并核验。
- **收藏**可从会话插件或其工具的详情中添加。对局结算里的 **收藏原来源** 会保存实际参与本回合的会话插件。收藏会把插件配置、随装依赖和已发现的工具保存在当前 Profile，原会话关闭或重启 DSH 后仍能从 **装备库 → 收藏** 取用。取消收藏后，已锁定的阵容仍保留自己的装备配置。
- **工具**来自原生工具清单与已打开的会话。DSH 注册工具时会记录插件来源，工具名和插件名可以不同。装配会沿用来源插件或插件组。装备库支持同一英雄组合不同 MCP 服务。
- **提供的工具**会在会话插件、Profile 插件和组合包卡片上列出能核验来源的工具，并标出它在当前阵容的装配状态。点 **查看工具** 可核对对应来源、试炼和换装影响。工具详情的 **来源插件** 可反查插件卡。回合结算的 **查看实战装备** 会带入该回合记录的工具来源。
- **条件工具**在装备库显示 **按条件启用**。例如 DSH `0.2.2-rc.2` 的队伍任务工具会随本局原生队伍模式开关显示状态。可以为它安排装备试炼，成功调用后才满足试炼条件。
- **执行器工具**也会出现在备战大厅。例如 PTC 模式的 `run_code` 可以随它的执行器装到招聘顾问身上，用程序编排多步取证或批量核对。英雄自带的执行器和对局中加载的执行器各有自己的来源。阵容对照、开局试炼和对局装备使用 DSH 实际提供的工具清单。战报记录能确认的执行器来源，成功调用按工具结算；能确认实际提供能力的执行器插件也获得经验。
- **Profile 执行器**提供的同名工具也可在 **装备来源** 中选择。替换前会列出要卸下的英雄自带执行器。选择会随阵容保存，开局核验实际执行器，经验计入该工具的实际来源和提供它的插件。
- **装备来源**在同一工具有多个可装配的插件时可选。装备库优先显示已收藏的来源。已保存阵容的名称会显示所选来源，阵容对照可用已保存阵容或原会话作对照，查看同一工具换装前后的来源。对局装备会显示能识别的注册来源。如果所选来源当前不可用，可以在装备详情换选其他来源。
- **替换来源**用于已识别的同层同名工具冲突。装备详情会在装配前列出同名工具、将换下的装备和受影响的其他工具。点 **替换来源** 或 **替换并装备** 后才会更新出装。能在独立会话层加载的来源可和英雄自带装备共存，开局时由 DSH 核验所选实现。
- **来源冲突**发生在 DSH 即将调用的工具与阵容中选定的来源不一致时。对局装备会提示等待原来源恢复或回城换装。因来源冲突而中止的调用也会写入战报。
- **动态工具**按其注册时机装配。装备库会记下预设插件和可保存的会话插件实际注册过的工具，包括只在某一回合短暂出现的工具。阵容或收藏保留了会话插件配置时，重启 DSH 后仍可从同一来源单独装配这些工具。同一插件组里的多个子插件提供同名工具时，各自发布的操作会绑定到实际注册工具的子插件。开局后，**回合触发**装备显示为 **待触发**，由 DSH 实际注册后变为 **已就绪**。刚发现的工具可通过 **刷新装备** 找到。
- **实战发现**保留成功使用过的临时工具。展开装备详情的 **实战发现来源**，可按实际来源回看首次发现的英雄、会话及来源熟练度。能复用的会话插件会在发现时记录配置及随装依赖，原会话关闭或 DSH 重启后仍可点 **收藏原来源**，再用 **试装此来源** 核对新阵容。旧记录可沿用原有的发现会话入口。仅能在原会话运行的来源保留实战记录，可通过 **配置装备来源** 另行提供能在新会话运行的插件。
- **补充工具来源**可用于只有工具卡、缺少可装配插件的能力。在卡片上选 **配置装备来源**，填入能在新会话提供同一工具的模块或 Cordis 配置，再选择注册时机。配置随装备保存在当前 Profile。开局工具会核验原工具的名称、参数和来源插件，回合工具在 **对局装备** 中显示实际注册状态。
- **Profile 插件**来自 DSH 的插件与组合包清单。可在装备库中启用已安装的兼容插件，也可进入 DSH 插件管理安装其他来源。Profile 级启用作用于整个 Profile。
- **Profile 动态工具**会按实际注册工具的插件配置记录。同名工具有多条已知来源时，可以选定其中一条。重启后，装备库仍会显示这些来源。停用或更改已选的插件配置后，使用它的阵容会提示来源缺失。
- **Profile 常驻工具**会显示已核验的具体插件来源。英雄自带插件注册了同名工具时，装备库会标明切到 Profile 来源需要卸下哪些自带装备。阵容对照、开局试炼和实战结算会使用同一来源身份。
- **装备市场**使用 DSH 的自定义插件索引。可以搜索当前 Profile 配置的索引，也可在市场内添加团队或社区索引。已有插件会显示当前版本，切换索引版本可以查看其 DSH 要求。选定兼容版本并确认安装来源后，DSH 执行原生安装检查。安装生效后，插件注册的英雄和工具会进入备战大厅。[DSH 插件索引说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/plugin-market.md)
- **DeepBlend Studio** 已在 DSH Web `0.2.1-rc.1`、DeepBlend `0.25.0`、Blender `5.2.1 LTS` 下验证。安装 DeepBlend 组合包并配置 Blender 后，备战大厅会读取它的两个原生预设和二十个工具。实际创建场景和预览后，可在对局中核对英雄、工具和会话插件的经验。DeepBlend `0.25.0` 的宿主版本范围以其包清单为准。[DeepBlend 0.25.0 发布说明](https://github.com/pearjelly/deep-blend/releases/tag/v0.25.0)
- **导入插件**可直接核对 npm 包名、Git 地址、安装包链接或本机绝对路径。npm 包会显示查到的确切版本，可选择软件源。安装与脚本许可沿用 DSH 插件管理，安装生效后刷新装备库。[DSH 插件管理说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/boot/plugin-manager/README.zh.md)
- **独立模块**可通过 npm 包名、本机模块目录、Git 仓库地址或安装包导入。DSH 会在读取 Git 仓库或安装包时识别模块类型。装备库的 **独立模块** 会列出当前 Profile 已安装的独立模块。点 **配置装备** 可带入模块名，填写参数、保存为会话装备后再给英雄装配。**已有配置** 会列出每种配置及它实际注册过的工具，点 **查看配置** 可进入该件装备，点 **新建配置** 可为同一个模块保存另一种用法。通过其他软件源安装 npm 包时，会核对该版本的安装包和校验值。pnpm 9 可能无法为 `git+file://` 生成锁文件，可使用本机目录导入当前工作树。
- **自定义装备**可用已安装的独立模块、本机模块文件或 Cordis YAML 配置制作装备。配置可以包含插件组、隔离域和一组插入操作。若使用相对路径，请填入原配置的加载目录。核对后装备会存入当前 Profile，装到英雄身上后由 DSH 在开局时核验并加载。[DSH 预设插件配置](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/preset/agent-preset/README.md)
- **精选装备**包括证据核验、网页检索、交付前复核、交付物预览。证据核验在关键依据不足时使用 DSH 原生提问，让顾问选择补证、降级推荐或暂缓提交。英雄自带的插件可替换时，装备库会列出将卸下的配置，再由玩家点击 **替换并装备**。历史搭配试装和装备接力也会显示这项换装。

工具来源按 DSH 的实际注册记录识别。启动前已存在的注册可通过内置工具映射或插件包的 `dsh.loadout.tools` 声明补足。只有原会话持有的运行时工具可从装备详情打开来源会话。阵容保存于对应 Profile 的 `agent-loadouts` 目录，自定义装备的配置存于其中的 `equipment` 子目录。

插件作者可在 `package.json` 的 `dsh.loadout` 下声明装备美术。`portraits` 按预设 ID 声明立绘，`equipmentArt` 为插件或组合包指定装备图，`toolArt` 按真实工具名声明专属图标。工具优先显示其实际来源包的专属图标，其次是装备图和 DSH 原生 `icon`。图片使用包内静态 PNG、JPEG 或 WebP，最大 4 MB。

```json
{
  "dsh": {
    "loadout": {
      "portraits": { "archive-agent": "./art/archive-agent.webp" },
      "equipmentArt": "./art/archive-kit.webp",
      "toolArt": { "lookup_archive": "./art/archive-lens.webp" },
      "roles": {
        "heroes": { "archive-agent": ["guard"] },
        "equipment": ["guard"],
        "tools": { "lookup_archive": ["scout", "guard"] },
        "bundle": ["support"]
      }
    }
  }
}
```

`roles` 接受 `general`（通用）、`scout`（侦察）、`craft`（制作）、`orchestration`（编排）、`guard`（核验）、`support`（支援）和 `specialist`（专精）。工具的声明来自提供该工具的包，适用于已登记的真实工具，并优先于自动归类。插件和组合包还会继承所属工具的职能。职能用于显示和筛选。

## 随包发布操作

在 `package.json` 的 `dsh.loadout.actions` 中声明操作。

- `heroes` 按 Agent Preset ID 声明。英雄使用声明预设的插件包提供的操作，也可以使用基础预设中唯一为该英雄声明操作的插件包。
- `equipment` 用于包内实际加载的预设插件、会话插件或 Profile 插件。组合包本身使用 `bundle` 声明操作。
- `tools` 按原生工具名声明。操作取自 DSH 确认的实际注册来源，随该工具的注册和来源状态变化。

每项操作包含稳定的 `id`、名称 `name`、指令 `instruction`，以及可选的 `detail` 和 `requiresInput`。例如，一个档案工具可以让使用者选择是否补证。

```json
{
  "tools": {
    "archive_index": [
      {
        "id": "request-evidence",
        "name": "补齐档案证据",
        "detail": "列出缺失出处和可核实的原始材料。",
        "instruction": "使用档案索引核对用户提供的档案号，列出仍需补齐的原始材料。",
        "requiresInput": true
      }
    ]
  }
}
```

操作在玩家点选后作为普通会话指令提交，沿用 DSH 当前会话的工具权限。工具操作还会带上该工具的原生名称。

## 登记面板操作

插件可在 `package.json` 的 `dsh.loadout.panelActivities` 登记由自己注册的 DSH 面板接口。接口使用 `connection.fetch.register` 的精确路径，接受缓冲的 JSON POST 请求。请求顶层的 `sessionId` 绑定当前会话。请求和成功响应分别按 `request`、`response` 中的顶层字段和值核对。为每项已完成的操作使用稳定的 `id`，让同一路径上的不同操作可以通过回执区分。

```json
{
  "panelActivities": [
    {
      "id": "save-route",
      "name": "保存路径",
      "detail": "在罗盘面板保存路径。",
      "path": "/api/example-compass",
      "request": { "action": "save" },
      "response": { "saved": true }
    }
  ]
}
```

条件值支持字符串、数字、布尔值和 `null`。请求和响应各最多读取 16 KiB。战报保存动作名称和提供该操作的装备名称。插件继续通过自己的接口处理权限、验证和保存。

通过 DSH 原生计划评审提交反馈的插件可在 `dsh.loadout.planReview` 登记 `id`、`name`、`detail` 和 `component`。其中 `component` 是 `conversation.composer` 槽中原组件的函数名。组件通过 `inject: () => ({ ctx })` 提供注册上下文，并调用原生 `matched.answer` 提交答复。英雄备战用组件所属插件、评审调用 ID 和宿主接受的答复摘要核对提交。结算适用于带文字修改意见的评审，使用浏览器的 Web Crypto 计算摘要。

## 验证

在本目录运行 `npm test`。测试用独立 Profile 启动本机 DSH，检查外部插件组、外部本地包、两个 MCP 服务、会话初始化和回合中注册的工具、会话专属插件跨英雄装配及阵容重启复用。阵容对照覆盖工具增减、就绪时机、随装依赖以及预览前后的保存状态。依赖测试会调用工具确认原阵容、新阵容和独立会话的服务实例各自正确。装备市场和直接导入使用测试包验证原生安装、来源核对和新装备入库。独立模块测试还会检查不兼容版本和校验失败的安装包，以及从 Git 和安装包导入的工具是否仅在装备后注册。续战测试使用本地测试模型走 DSH 原生循环。可用 `DSH_LOADOUT_TEST_BINARY` 指定桌面版随附的 CLI。
