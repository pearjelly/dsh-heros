# DSH-Heros

Choose a DeepSeek Harness agent preset and equip it with tools and plugins. Preview what the loadout can do before you start, then see which tools ran and what the agent delivered.

[![The DSH-Heros lobby with the hero roster on the left and tools and plugins on the right][armory]][armory]

[Install on Web or Desktop](https://github.com/pearjelly/dsh-heros#install) · [21-second demo (Mandarin, MP4)](https://github.com/pearjelly/dsh-heros/releases/download/v0.67.1/dsh-heros-promo-standard-narrated-zh.mp4)

## One supply card, two handoffs

After installing, open **DSH-Heros → Armory → Lighthouse hero trial** from the DSH sidebar. With the supported stock Standard and Minimal presets enabled, select **Openable original**. Open and send the built-in task once with each hero.

[![The Lighthouse trial lets you choose an original file or a summary, then pick Standard or Minimal][trial]][trial]

When both runs are complete, choose **View the hero trial** from the session. In this example, Standard attached the original supply card. Minimal read the card and handed off a text summary. Add **Deliverable Preview** to Minimal and replay the same task to try a file handoff.

[![The completed Lighthouse runs show one attachment from Standard and zero from Minimal][results]][results]

## Take the loadout into your own work

In the lobby, select **Choose a loadout**, pick a hero and gear, then choose **Use this loadout on a task**. Pick your files, write the task, and review the tools before opening a DSH draft. Save combinations as loadout plans to use them again.
