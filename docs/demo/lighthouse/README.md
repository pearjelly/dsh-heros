# 灯塔补给行动 · Lighthouse Supply Run

当前版本可以在深度荣耀大厅直接打开 **灯塔补给行动**。以下步骤配合首页安装与实战视频，演示手动配出同一套连携。

Current versions open **Lighthouse Supply Run** directly from the lobby. The steps below follow the homepage video and let you build the combo manually.

三张补给卡是虚构的演示材料。把三张卡和 `AGENTS.md` 放进一个空目录，在 DSH 中把它添加为工作区。`AGENTS.md` 提醒模型在同一回合先查找再交付。

在深度荣耀选 **标准模式**，给 `glob` 试装 **交付物预览**，选择 **同回合基础连携**。开局委托的任务目标填「灯塔补给行动」，把 [任务文本](first-turn.zh.txt) 粘到 **首回合任务（选填）**。开局后发送任务。确认对话里的 `02-灯塔.md` 能打开，再验收委托。

Copy the three fictional supply cards and `AGENTS.md` into an empty folder and add it as a DSH workspace. The instructions guide the model through both tools in one turn. Use `glob` and **Deliverable Preview** in a basic same-round combo. Paste the [sample prompt](first-turn.zh.txt) into the optional first-turn task, then send it from the session. Open `02-灯塔.md` from the conversation and claim the combo reward.
